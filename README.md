# Tower Lab — Laboratório de Roteiros

Site estático publicado na Vercel (projeto `tower-lab`). Cada commit na branch `main` republica o site.

## Arquivos
- `index.html` — o site inteiro (HTML, CSS e JS num arquivo só): roteiros (prontos, com a linha de raciocínio ligação → vídeo → referência, e o montador de roteiro novo), banco de ideias e Stories, ganchos e método, referências e estatísticas do Instagram.
- `data/instagram.json` — estatísticas do perfil @towerhomeloans_esp exportadas do Meta Business Suite. Atualização manual.
- `vercel.json` e `robots.txt` — mantêm o site fora dos buscadores.

Este repositório não guarda dados financeiros nem de anúncios.
